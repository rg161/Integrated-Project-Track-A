# Source and model notice

The TurtleBot3 Waffle Pi, tyre and LiDAR visual meshes in `models/robotis_tb3/assets/`
come from the ROBOTIS model package. The associated Apache License 2.0 text is kept at
`models/robotis_tb3/LICENSE`.

`models/track_a_scene.xml` is the project scene used at runtime. It combines the robot,
room, obstacles, LiDAR/camera definitions, charging station, ArUco marker and docking
perimeter required for this assessment.

No archived/reference implementation is included in this cleaned submission build; the
active implementation is the code in `track_a/`.
